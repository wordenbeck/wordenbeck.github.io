# wordenbeck.github.io

Portfolio von Thomas Wordenbeck: Produkte für den eigenen Alltag und für Menschen im Umfeld.

- Texte (DE/EN) und Projektdaten: `content.js`
- Aufbau und Aussehen: `assets/` (`app.js` Startseite, `glas-ui.js` Projekt-, Warum- und Über-mich-Seite, `core.js` gemeinsame Helfer)
- Seiten neu erzeugen: `python3 _build/make-pages.py`
- Demo-Kopien der Apps neu erzeugen: `python3 _build/make-demos.py`
- Mahlzeit-Demo bauen: siehe `_build/mahlzeit/vite.config.mjs`
- Verlauf der Gestaltung: `HISTORIE.md` (alter Stand in Git: Markierung `v1`, Entwürfe im Zweig `historie`)
